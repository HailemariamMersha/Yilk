# Yilk
## *"Before You Spend... Yilk It."*



---

## 🎯 Vision
A smarter, emotionally-aware spending assistant that helps users evaluate purchases and discover what's truly worth their money.

## 🚀 Key Features

### 🥇 1. **Money Comparison Engine** (Flagship Feature)
**Transform prices into context**

Helps users visualize what else their money could buy before making a purchase. Turns abstract numbers into meaningful comparisons.

**Example:**
> "AED 200 = 3 movie tickets + 1 dinner + 1 month Netflix"

**Implementation:**
- **MVP**: Simple input field with hardcoded/dynamic alternatives
- **Phase 2**: AI-powered personalized comparisons
- **Categories**: Essentials, Experiences, Investments

---

### 🧠 2. **Purchase Worth Rating**
**AI-powered purchase recommendations**

Helps users decide if something is actually worth it based on real user feedback and AI analysis.

**Features:**
- Community-driven thumbs up/down system
- Optional reasoning collection
- AI-generated verdicts (e.g., "70% of people find this worth it")
- "Yilk Score" per item with user discussions

---

### 🔔 3. **Impulse Buy Alerts**
**Smart notifications for mindful spending**

Detects impulsive purchases and encourages reflection before buying.

**How it works:**
- Triggers alerts for spending over user-defined thresholds
- Time-based suggestions ("Revisit in 24 hours")
- Context-aware warnings (time of day, spending patterns)
- Gentle modal prompts with reflection questions

---

### 💬 4. **Yilk Reviews – Real Value Ratings**
**Community-driven purchase insights**

A public feed where users share their spending experiences and whether purchases were worth it.

**Features:**
- Upvotable product review feed
- Tags like #goodbuy, #regret, #worthit
- User profiles with track record
- Short notes with verdict summaries

---

### 📩 5. **Waitlist + Early Feedback**
**Community building and market validation**

Gather early users and feedback through integrated forms.

**Current Implementation:**
- Google Forms integration on landing page
- Early access incentives
- Custom feature requests collection
- User spending habit surveys

---

### 🌍 6. **Localization & Culture-Aware Comparisons**
**Global spending context**

Price comparisons based on local currencies, regional prices, and cultural spending patterns.

**Features:**
- Multi-currency support (AED, ETB, USD, etc.)
- IP-based suggestions
- Cultural examples ("This = 5 buna sessions in Addis")
- Regional spending habit analysis

---

### 📱 7. **Chrome Extension** (Future)
**Seamless integration with online shopping**

Auto-detects prices on product pages and activates Yilk comparison popup.

**Planned Features:**
- Content script integration
- ML-based price detection
- Real-time Yilk popup on shopping sites
- Amazon, Noon, and major retailer support

---

## 🛠️ Tech Stack

- **Frontend**: React + Tailwind CSS
- **Backend**: Node.js + Firebase/Supabase
- **Database**: JSON/Airtable (MVP) → PostgreSQL (Production)
- **AI/ML**: OpenAI API for purchase analysis
- **Extension**: Chrome Extension APIs + Content Scripts
